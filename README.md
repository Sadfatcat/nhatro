# Quản Lý Nhà Trọ

Monorepo tối giản cho dự án quản lý nhà trọ.

## Workspaces

- `apps/cms`: Angular CMS/frontend hiện tại.
- `apps/api`: vị trí thêm NestJS backend sau.
- `packages/shared-types`: type dùng chung.
- `packages/shared-auth`: role/permission mapping.
- `packages/shared-mocks`: mock data cho frontend-first.
- `packages/ui`: UI package dự phòng khi component thật sự cần dùng chung.

## Scripts

```bash
npm run cms:startcl
npm run cms:build
npm run cms:test
```
